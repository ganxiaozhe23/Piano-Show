# Piano Show

Minecraft Java/Fabric 的钢琴像素画演出工具。项目由两个独立部分组成：

- `editor/`：离线编排器，将 MIDI 和图片编译成版本化的 `.pshow` 包。
- `mod/`：Fabric 1.21.x 服务端 Mod，负责加载编排包、调度音符、生成飞行方块并落地成画。

## 快速开始（编排器）

需要 Python 3.11+：

```powershell
cd editor
python -m pip install -e .
piano-show import --midi song.mid --image image.png --out show.pshow --resolution 128 --orientation wall_north --pixel-scale 2
```

也可以直接运行模块：

```powershell
python -m piano_show import --midi song.mid --image image.png --out show.pshow
```

安装 `piano-show[gui]` 后可运行 `piano-show gui` 打开一个轻量桌面编排窗口；GUI 与 CLI 使用完全相同的编译器和文件格式。

默认使用 32 色 Minecraft 方块调色板，透明像素不会生成方块。输出包是 ZIP 文件，包含 `manifest.json`、`events.bin`、`pixels.bin`、`palette.json`、`preview.png`、`layout.json` 和可供离线预览使用的 `preview.json`。新包为 v2：默认墙面画布、2 倍像素缩放、Display 插值和自适应飞行；旧 v1 包仍可加载。

启动本地 Web 预览：

```powershell
piano-show preview --show show.pshow --open
```

启动完整本地编辑器并一键启动 Minecraft 调试：

```powershell
piano-show editor
```

编辑器中的“启动 Minecraft 调试”会编译当前 `.pwork`、复制 v2 `.pshow` 到 `mod/run/config/piano-shows`，并启动 Fabric `runClient`。游戏内仍需手动执行页面显示的 `/piano load`、`/piano build` 和 `/piano play` 命令。

如果还没有 `.pwork` 工程，可先创建一个：

```powershell
piano-show project --midi song.mid --image image.png --out demo.pwork --name demo
```

编辑器现在提供本地调试控制：打开 `piano-show editor` 后选择 `.pwork`，点击“启动 Minecraft 调试”。它会自动编译并复制演出包、启动或复用 Fabric 开发客户端，并在右侧显示日志。进入游戏后按面板提示执行命令；点击“停止调试”只停止当前客户端，不删除世界和日志。

## Mod 开发

`mod/` 是 Fabric Loom 工程，目标为 Java 21 和 Minecraft 1.21.1。安装 Gradle 后可运行：

```powershell
cd mod
gradle build
```

将生成的 Mod 放进服务端 `mods/`，把 `.pshow` 文件放入 `config/piano-shows/`，然后使用：

```text
/piano load show.pshow
/piano build 0 64 0
/piano preview
/piano play
```

调试飞行实体和落点：

```text
/piano debug falling
/piano debug target <queueIndex>
/piano debug clear_entities
```

The default generated show uses a scaled vertical wall canvas. The keyboard is a full 88-key layout with separate white/black key models and pressed-key highlighting; v2 image payloads use client-interpolated Display entities and the image backing/border are generated by `/piano build`.

当前 Mod 核心已经包含包加载、服务端 tick 调度、管理员命令、Display/FallingBlock 双视觉模式、精确像素落地队列和 88 键布局生成。编排器默认使用确定性的空间随机像素顺序，画面会从多个区域同时形成，而不是逐行扫描；旧蛇形包仍可兼容加载。

默认 v2 飞行预算为 512 个活动 Display、每 tick 生成 32–64 个载荷、飞行 12–36 tick，并依据音符密度与队列积压自适应。

## 设计约束

- 编排结果由输入文件哈希和随机种子决定，重复编译可复现。
- MIDI 事件按稳定顺序量化到 20 TPS。
- 图片像素使用蛇形扫描线分配到音符事件，保证最终像素不遗漏。
- Display/FallingBlock 载荷和方块写入均有每 tick 预算，避免短时间创建过多实体。
